Requested by the owner: "is the text still accurate given all of the changes that have been made to the tool? would you change any of it?" — followed by "yes please" to authorize the rewrite.

Why the old text was stale

The methodology paragraph under the Pilot Analyzer's "How effective HP and DPS are calculated" panel hadn't been updated as later bug fixes added new calculation mechanisms. A code audit (grepping the live calculation functions directly, not relying on memory) found one outright false claim and several real omissions:

IssueWhat the code actually does
False claim: "doesn't model Reactive Armor Hardeners"It is modeled — simulateReactiveArmorHardener() ports pyfa/eos's own donor/recipient resist-shifting logic, run against a flat 25%-per-type incoming-damage assumption (pyfa's own default) until the result converges or settles into a repeating cycle.
Omission: hull-intrinsic resist skill bonusSHIP_RESIST_BONUS (e.g. a Nighthawk's Caldari Battlecruiser all-shield-resist skill) is a separate, non-stacking-penalized resistance layer alongside Damage Control and hardeners — not mentioned anywhere in the old text.
Omission: Fighter Bay DPSFighters (carriers/supercarriers/FAXes) are counted the same way drones are — capped by launch tubes and per-class (light/support/heavy) limits, hardest-hitting squadrons first — with their own "Fighters" skill (damage only, no RoF counterpart). Added in the 2026-10-08 Fighter Bay fix, never folded into this text.
Omission: Bastion/Siege/Triage/Industrial Core RoF doublingThese modules double turret/launcher RoF while active (assumed active whenever fitted) — added in the 2026-10-08 Bastion fix, never folded into this text.
Omission: Fleet Hangar in the ammo-fallback guessThe cargo-ammo fallback guess also checks the Fleet Hangar (flag 155) — added in the bug #25 fix, never folded into this text.
Omission: Vorton Projector's distinct skill treeEDENCOM's Vorton Projector trains on its own 3-skill tree, separate from ordinary turret skills — never mentioned. (Precursor/Entropic Disintegrator weapons were confirmed to correctly reuse the normal turret skill tree, so no mention was needed there.)

The Tactical Destroyer Mode explanatory text (the other collapsible panel) was separately audited and found still fully accurate — no change made there.

The fix

Rewrote the <div class="note"> inside the "How effective HP and DPS are calculated" panel to correct the RAH claim and fold in all five omissions above, in the same dense prose style as the rest of the text. No calculation code was touched — this is a pure explanatory-text change.
