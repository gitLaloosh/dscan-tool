My Ship, phase 1: save your fit and switch to it from any threat

Feature 2026-10-23 · v2026.10.14.32 → v2026.10.14.33 · Erik: "ok, work on 1" (build My Ship phase 1 as drawn in the "My ship" design canvas). Decisions M1–M7 are in roadmap/my-ship-plan.md.

What changed

  • Chip and switch on every tab, at the right end of the tab row: "+ My Ship" with "Use in assessments" disabled until a fit is saved; then "MY SHIP · Vexor · Brawl" with the switch on.
  • The panel (a popover; a sheet from the bottom on a phone). Empty: paste an EFT fit, Save as my ship. Set: the ship, its class and the date, six numbers (EHP, DPS, capacitor, speed with the prop module on, signature with an MWD on, lock range), the EFT text, Open in Fit Analyzer, Replace, Copy EFT, and Delete with an inline "Delete / Keep it". Escape, the X or a click outside closes it.
  • Fit Analyzer. "Set as my ship" beside any analyzed fit's name; it keeps that fit's current module states and then reads "This is my ship". "Open in Fit Analyzer" shows the saved ship under a "Viewing my ship" banner with Replace fit and Analyze another fit.
  • Threat ⇄ my ship switch (M5) above the results in the Fit Analyzer and the Pilot Analyzer, while a ship is saved and "Use in assessments" is on. Threat is amber, my ship cyan. Showing my ship hides the threat; the threat's own module changes stay (M7: they're forgotten only when a new threat is loaded). On a phone the switch stays at the top while scrolling.
  • Module states are kept with your ship (M4): every module, drone, mode or ASB change on any My Ship view is saved, and shows on the other views. The Fit card's reset icon returns to the pasted states.
  • Storage: this browser only (localStorage dscanMyShip): the EFT text, the states, the switch and the date. The numbers are not stored. The fit is recomputed from the text the first time a page load needs it, so tool fixes and game-data updates apply; no ESI request is made just for loading the page.
  • Two new error codes: MYSHIP-01 (the browser refuses storage: My Ship still works until the page closes) and MYSHIP-02 (the saved fit no longer loads; the message includes the underlying code, for example FIT-03, and the saved text is kept). ERRORS.md regenerated, 25 codes.
  • Code: the MY SHIP block at the end of the script. The Fit Analyzer's paste-to-fit step is now buildFitFromEft(), shared with My Ship (same engine calls). The wiring for one fit layout is wireFitLayout(), used by the Fit Analyzer, each Pilot Analyzer loss and every My Ship view (it was the same code twice). Class names are mys-*, since ms-* already means module state.

Not in phase 1

Nothing compares the two fits yet: no matchup strip, no "vs my ship" numbers, no amber changed numbers (M6), no Weaknesses from your side. Those need the turret-application decisions (D1–D6).

Lesson for future models

  • Code that runs when the page loads also runs inside the regression suites, which load the same script with a stub DOM (no classList, no localStorage). If start-up code touches either, the suites stop before checking a fit, and the browser-based page checks can't show it. Guard start-up code (myShipInit returns early on a stub element) and run the Node suites after adding any (LESSON #36).
  • When one view replaces another after a tick, keep the page's height until the new view is drawn. Otherwise the browser clamps the scroll to the top. Check scrollY before and after the swap (LESSON #33).
