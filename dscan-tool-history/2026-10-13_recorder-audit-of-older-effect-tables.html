What was done

The capacitor, HP, sensor, repair, shield-recharge and signature tables were first built by text-matching pyfa's effects.py. The weapon-range batch showed that text matching misses handlers.

The new tools/audit_effect_tables.py runs every pyfa handler carried by a ship, module, rig, subsystem or skill. It then compares, row by row, with the tables in index.html. For each stat it checks:

  • effects pyfa uses that the table lacks
  • table rows pyfa doesn't use
  • source-attribute, filter, stacking and skill-level differences
  • the skill rows

After the fixes the audit runs clean. Deliberate exclusions are listed in the script's KNOWN list with reasons, for example:

  • "while active" Capital Sensor Arrays, Entosis Links, MJD signature spikes and the Signature Suppressor's active burst, all for the module-toggle item
  • Triage's +900,000,000% EWAR cap need, which is how the game blocks EWAR in triage
  • a T3D HP effect whose value is 0 on every hull

Verification

  • Three new constructed golden fits (Apostle in triage, Valravn, Exequror) plus pins on the four Bastion fixtures. v.18 fails 7 checks.
  • Full output diff v.18 → v.19 changed only the Bastion sensor strengths among existing fits.
  • 123/123 PASS, 280/280 parse tests. node --check clean.
  • Playwright render of the Paladin shows 50.4 with the updated note "includes a fitted Sensor Booster, Signal Amplifier or Bastion bonus".

Lesson for future models

The first audit run gave Triage's remote rows the wrong skill filter. pyfa builds filter lambdas in a loop, and the recorder evaluated them after the loop had finished, so every lambda saw the last skill. The recorder now evaluates filters at call time (run(eid, ctx, evaluator)). See LESSONS_LEARNED.md #16.

Also: five fixtures had ship records without scan-strength attributes, so the Vargur showed 0 before and after the fix. They were back-filled from the SDE (#6).

Still not covered by the audit

  • Speed/agility/mass: still group-gated code rather than a table.
  • Damage/rate of fire: SHIP_ROLE_BONUS is still hand-made.
  • Drones and EWAR.

These are the next candidates for the same treatment.
