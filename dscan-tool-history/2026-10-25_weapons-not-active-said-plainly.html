A weapon that isn't Active: the cards say so

FixTests 2026-10-25 · v2026.10.14.67 → v2026.10.14.68.

The owner sent a screenshot ("showing zero dps in firepower card"). In it, his Nergal is My Ship, shown in the Pilot Analyzer against a Vargur. The page said:

  • Firepower: 0, "drones and fixed weapons only";
  • Damage Application: "Your ship has no turrets, missiles, ...";
  • the Matchup: 0 DPS applied to them.

Cause: the saved Nergal's Light Entropic Disintegrator II wasn't set to Active. Its ring tile shows the Online dot, and the Fit card's reset icon is lit. A module below Active deals no damage, in pyfa too, so the 0 is right. The words hid the reason.

Reproduced: the same fit as My Ship with the gun set to Offline gave exactly those three texts. Separately, at 88.7 km (the Vargur's range) even an Active disintegrator applies 0, which is also right.

The owner chose "Say it plainly".

What changed

  • Engine: estimate.inactiveWeapons lists the weapon types in high slots with no copy Active: {typeId, name, count, state 'online' | 'offline'}. Display only; no number changes.
  • Firepower: the Total DPS line reads "weapons not active" instead of "drones and fixed weapons only". The hover says "Light Entropic Disintegrator II is offline: it doesn't fire (as in pyfa). Set it Active in your fit to count it."
  • Damage Application: the same sentence replaces "no turrets, missiles, ...", on both your card and the threat's ("Their ... ").
  • Matchup: "DPS applied to them / you" carries the sentence on hover, and so does the "they last" / "you last" explanation.

Checks

  • tools/page_checks/assumed_charge_check.py has 3 new checks: the Nergal as My Ship, gun switched off. Firepower, Damage Application and the Matchup must each name it. v.67 fails all 3.
  • Regression ALL PASS, update chain all 37 steps OK, all 19 page checks 0 failures.

Lesson for future models

LESSON #63: when a number is 0, show the cause the tool knows, not a guess about the fit.

  • "Drones and fixed weapons only" and "no turrets" were written for fits with no guns. They also showed when the gun was there but switched off, so the user couldn't see why.
  • Before writing a fallback sentence, list every way the number can reach that branch, and give each its own words.
