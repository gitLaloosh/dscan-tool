Module states: module list with on/off controls (plan Phase 2)

Feature 2026-10-13 · v2026.10.13.21 → v2026.10.13.22 · Erik: "ok make the fix and then move on to phase 2"

What changed

The Fit card now lists every fitted module copy with a state button: Active (filled dot), Online (hollow dot) or Offline (dashed dot, row dimmed). The state is always written out, so colour is never the only cue.

  • Click to change. A click moves that copy to the next state, in pyfa's order: offline → online → active → offline. States the game wouldn't allow are skipped, and the button's hover text says why. For example, on the Vargur's MJD: "Can't be active: Bastion Module I blocks activation while it runs." Hover also shows why a module starts online ("Assumed online: micro jump drive").
  • Everything recalculates. The engine runs again with the new states, so every card updates. On Tactical Destroyers all three modes are recalculated, so switching mode keeps the chosen module states.
  • Reset to best case appears once any state has been changed. The header otherwise reads "Module states assumed: best case".
  • Refused changes are explained. If a later change makes an earlier one impossible (switching Bastion on while the MJD is running), the engine refuses it. The card then says why, and the MJD shows as online.
  • Where it appears (Erik's D1):
    • Fit Analyzer: always open.
    • Each Pilot Analyzer loss: collapsed by default ("show modules and states"). Each loss keeps its own states.
  • Rows: rigs and subsystems show a fixed "Online" tag. Charges, drones and cargo stay plain rows. Module icons come from CCP's image server (images.evetech.net/types/{id}/icon). The row you click is the row that changes; copies of one type are interchangeable to the engine.
  • Text: the methodology note now mentions the Fit card controls.

Verification

Playwright, against the real page, with ESI answered from the SDE:

  • Rifter with dual prop. Drain 11.9 at default. Clicking the AB skips "active", because only one propulsion module can be active, and goes to offline.
    • MWD off: drain 8.9, capacity 313 (the MWD's capacity penalty is gone).
    • AB on: drain 9.6.
    • Reset: back to 11.9 / 250.
    These match check_module_states.py.
  • Vargur. The MJD can't go active while Bastion runs. With Bastion off and the MJD active, drain is 123.3. Switching Bastion back on refuses the MJD with the reason shown.
  • Pilot Analyzer. Collapsed by default, stays open after a change, and each loss tab recalculates on its own.
  • Hecate. A blaster switched off stays off across Defense/Sharpshooter mode switches: DPS 127 → 63, and 63 again after returning to Sharpshooter.
  • No console errors. 139/139 regression fits and 280/280 parse tests pass; the engine is unchanged apart from where a hover note is attached.
