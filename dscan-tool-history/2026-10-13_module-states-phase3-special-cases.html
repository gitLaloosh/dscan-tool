Lesson for future models

A stat isn't only the sum of the effects that modify it. pyfa also caps an attribute at its maxAttributeID, and reads a module's cycle time from several attributes. Both bugs had been there since the targeting and capacitor batches, because those batches only listed modifiers. For every stat, also read the attribute's SDE record (min/max attribute, default value) and the pyfa property that reads it. See LESSONS_LEARNED.md #20.

Found along the way (not changed)

  • Entosis Link speed limit: it has a 4,000 m/s cap (speedLimit). pyfa's handler writes it where its maxSpeed never reads it, so pyfa doesn't apply it. Left out to match pyfa.
  • Triage locked targets: Triage also raises max locked targets, which the tool doesn't show.
