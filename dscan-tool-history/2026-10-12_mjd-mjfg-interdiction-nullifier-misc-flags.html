Micro Jump Drive / Field Generator + Interdiction Nullifier now flagged in EWAR / Misc

2026-10-12 · index.html · from the architecture backlog (2026-10-12 full-module-dogma-audit) · the owner: "Micro Jump Drives and interdiction nullifiers can be flagged in the Misc category of the ewar card. Any disagreement there?" -> "Go ahead"

Finding

Both backlog items ("Interdiction Nullifier module has zero representation" / "Micro Jump Drive / Micro Jump Field Generator have zero representation") were agreed as presence-only flags, same mechanism as the existing cyno flag (MISC_TRAIT_GROUP_INFO). Re-verified all three real ESI groups directly against the local pyfa SDE cache before implementing, surfacing a few corrections to the backlog's original notes:

GroupReal typesKey attributes (live-confirmed)

All 3 effects are non-"Active" (no activation cycle attribute present) — genuinely passive while fit, unlike Sensor Booster/MJD/Bastion's assumed-active convention.

Fix

Extended MISC_TRAIT_GROUP_INFO with 3 new entries, keyed by each real lowercased ESI group name. Interdiction Nullifier's note is a plain static string (its tradeoff % is uniform across every real type). MJD's and MJFG's notes are instead function(dogma) — the sig-bonus%/duration genuinely vary by variant, so hardcoding "150%/12s" would have been silently wrong for the Xarasier MJD. The push site (defensiveTypesFiltered loop) now resolves typeof miscInfo.note === 'function' ? miscInfo.note(dogma) : miscInfo.note before pushing, so ewarCardHtml() always receives a plain string either way — no render-side change needed.

New attribute constants: MJD_SIG_RADIUS_BONUS_ATTR=973, MJFG_JUMP_RANGE_ATTR=2066, MJFG_FLEET_RADIUS_ATTR=2067, INTERDICTION_NULLIFIER_SCAN_RES_ATTR=565, INTERDICTION_NULLIFIER_DRONE_BW_ATTR=3124. Interdiction Nullifier's targeting-range tradeoff reuses the EXISTING EWAR_TARGETING_RANGE_BONUS_ATTR=309 (same real attribute Sensor Dampener already reads) rather than a duplicate constant — safe since it's gated to a different group name, same collision-avoidance principle as every other fix in this file.
