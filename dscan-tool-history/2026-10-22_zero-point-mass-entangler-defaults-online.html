What changed

  • A fitted Zero-Point Mass Entangler (Heavy Interdictors, Odysseus) now defaults to online, like a cyno, cloak or MJD. Active, it pins the ship in place (pyfa Effect7142: speed ×0.05, mass ×0.2, can't warp, MWD blocked). A HIC runs it only once it's tackled, so assuming it's active made every HIC carrying one read as nearly stationary.
  • It's still one click to set it active in the module list, and the active numbers are pyfa-exact as before. The module's note reads "Assumed online: zero-point mass entangler".
  • This is an input choice, outside the PYFA CORE sections: effect 7142 added to MODULE_DEFAULT_ONLINE_EFFECTS, and the same id added to golden_oracle.py's copy. DEVIATIONS.md lists it with the other default-online modules.
