EWAR hull bonus sweep: non-Recon hulls (independent review finding #12)

2026-10-11 — dscan-tool.html

The problem

SHIP_EWAR_BONUS was built and audited only against the 8 dedicated T2 Recon Ships (Rook/Falcon, Huginn/Rapier, Lachesis/Arazu, Curse/Pilgrim). Its own leading comment said so explicitly: "All 8 T2 Recon Ships checked." Every other hull in the game with a genuine ship-intrinsic EWAR bonus — the entire T1 EWAR frigate/cruiser line, the ECM battleships, the T2 Electronic Attack Ships, and several one-off role bonuses — was a silent gap: the tool would show a fitted ECM/Damp/Paint/Weapon-Disruptor module's base numbers only, understating its real effectiveness whenever the firing ship itself carried a hull bonus.

Method

Same exhaustive-sweep discipline established for finding #5 (SHIP_RESIST_BONUS), adapted for EWAR:

  1. Re-ran the full ESI sweep: /universe/categories/6 → all 50 ship groups → all 424 published hull types → all 1,350 unique dogma_effects referenced across them.
  2. Filtered twice, independently: once by effect name keyword (ecm/jam/damp/paint/trackingdisrupt/guidancedisrupt/weapondisrupt/sensorlink), and once by modified-attribute id (238-241 ECM strength, 2044 shared falloff, 554/54 target-painter magnitude+range, 309/566 sensor-dampener, 351/349/767 tracking disruptor, 547/596/847/848 guidance disruptor, 105 scram strength, 20 web strength). The attribute filter caught hulls the name filter missed — e.g. Crucifier's own tracking-disruptor-range effect is literally named shipBonusTDOptimalBonusAF1, no "trackingdisrupt" substring anywhere.
  3. Every magnitude cross-checked against ref-data.everef.net's own Traits payload, which tags each bonus either role_bonuses (FLAT, never skill-scaled) or types[skillId] (PER-LEVEL, ×5 at this project's assumed-max-skill-V convention) — the raw dogma magnitude alone can't tell those apart, same lesson as the finding #5 resist sweep.

What was found

25 hulls added or extended in SHIP_EWAR_BONUS (20 brand-new entries across T1 EWAR frigates/cruisers, ECM battleships/black ops, Electronic Attack Ships, a Marauder, a Navy Issue dreadnought, a Navy Issue frigate, 2 pirate-faction ships, 1 Faction Warfare LP-store frigate, 3 SOE/Drifter-tech faction analogs of the Recon line — plus a wholly new EWAR entry for the Monitor, which already had a SHIP_RESIST_BONUS entry from finding #5 but no EWAR entry at all).

Most consequential single finding: the Monitor. It doesn't just lack an entry — it has a genuinely counter-intuitive one. A Monitor's Target Painter is reduced to 0.0375% effectiveness (essentially nothing) while its range is quadrupled. A Monitor showing a Target Painter on d-scan is not meaningfully painting anyone's signature, despite the module being lit — a threat read that would have been flatly wrong without this fix.

Deliberately out of scope (disclosed, not silent)

  • 6 Rookie ships (Reaper/Impairor/Ibis/Velator/Hematos/Violator) — real, flat bonuses, but vanishingly unlikely to matter on a d-scan read of an actual engagement.
  • Griffin Navy Issue — its only EWAR-adjacent effect is an ECM-drone jam-duration bonus (a drone mechanic this table doesn't model). It genuinely traded away the real ECM module bonus for a turret-damage bonus; this is not an omission.
  • Python — Alliance Tournament-exclusive reward ship.
  • Maulus Navy Issue's flat scrambler-strength dogma row (effect 6358, +2 flat) — present in dogma_effects but absent from its own Traits text, so left out rather than guessed at (the per-level/flat ambiguity-resolution source itself didn't corroborate it).
  • ECM Burst Jammer module group — already a disclosed, pre-existing EWAR_GROUP_INFO gap (deferred before this fix); not reopened here. Scorpion's regular ECM Target Jammer numbers are unaffected.
