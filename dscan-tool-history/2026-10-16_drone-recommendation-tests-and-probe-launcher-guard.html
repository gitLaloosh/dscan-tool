Lesson for future models

  • Write the first test of a function from its stated rule, at every edge of every threshold, including 0. The speed-0 case slipped through because "no speed known" and "speed 0" were the same test (> 0). An untested branch that "obviously works" is where these hide.
  • A bug-list item can be fixed and still lack a test. Before closing it, add a regression fit that fails if the fix is reverted.
