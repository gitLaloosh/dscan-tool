EHP: hull, rig, coating and subsystem HP modifiers

Feature backlogAudit batch 4 2026-10-13 · v2026.10.13.13 → v2026.10.13.14

What changed

The HP pools used to read a fixed set of item attributes. They are now driven by each item's real dogma effects, following every pyfa handler that changes the ship's shieldCapacity, armorHP or hp. That's the new SHIP_HP_ATTR_EFFECTS table, with values from CCP's SDE.

None of these handlers is stacking-penalized in pyfa. Items with no effect data (old trimmed test records) fall back to the previous code path.

Verification

Expected values come from an independent hand-coded Python derivation (indep_hp.py): pyfa rules and SDE values, not the tool's table. Both new constructed fits match exactly:

  • Megathron (plate, Layered Energized Membrane, Layered Coating, Reinforced Bulkheads, PDS, LSE; Trimark, Transverse Bulkhead and Polycarbon rigs): raw shield, armor and hull 15,921 / 25,855 / 16,758.
  • Guardian (plate with the logistics bonus, extender, Ionic Field Projector penalty): 2,559 / 10,886 / 2,505.
