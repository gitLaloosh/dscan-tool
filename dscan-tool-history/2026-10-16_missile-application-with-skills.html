Missile recommendation with application skills

Calculation 2026-10-16 · v2026.10.14.26 → v2026.10.14.27 · Erik: "4. do it", the last part of item 4 (hand-tables optional P5: "the missile recommendation uses raw charge explosion radius / velocity").

What changed

  • The Weaknesses card's missile pick is what you fire at this target. Your missiles now get the tool's standing All V skills. pyfa has exactly two skill handlers on a missile's application:
    • Guided Missile Precision, Effect1472: explosion radius −5% per level, ×0.75 at V;
    • Target Navigation Prediction, Effect1590: explosion velocity +10% per level, ×1.5 at V.
    Both are unpenalized and apply to every charge requiring Missile Launcher Operation (every missile).
  • The formula is unchanged: min(1, S/E, (S/E × Ve/Vt)^drf). pyfa's own application graph uses the same one (graphs/.../launcher.py calcMissileFactor).
  • Still not applied, because they're unknown here (DEVIATIONS.md): your own rigs (Rigor, Flare), Missile Guidance Computers and hull bonuses.
  • The result carries missileApplication.inputs: the unrounded target signature and speed each ranking used.

Effect

Missiles land better, so the ranking moves on most fits (only missileApplication fields change; every other number is identical). Re-pinned fits:

Verification

  • New tools/independent_checks/check_missile_application.py, in the chain:
    • Part 1 runs pyfa's handlers for every published skill and must find exactly those two, so a pyfa or SDE change fails it.
    • Part 2 recomputes every golden fit's ranking from SDE ammo values: 247 rankings, 0 mismatches. v.26 fails it.
  • Suite ALL PASS (3 fits re-pinned with notes). Chain all 25 OK, parse tests 293/293, layout and missing-charges page checks FAILURES 0.

Lesson for future models

  • Before applying "max skills" to a number, decide whose number it is. These missiles belong to the viewer, so the viewer's All V skills apply. The target's own skills and fit were never involved, and the viewer's fit is unknown.
