Part 2 — Why the 2026-10-12 full-module audit missed this

  1. Wrong data on the one row that mattered. The 10-12 audit reported Industrial Cores as carrying "2351 (ewar resistance) only." The real item carries about 20 bonus attributes, including drone damage. That session's re-verification only checked group 515 for the Siege/Bastion weapon attribute IDs, never the full attribute list.
  2. One sample per group. The research pass sampled a single representative item per group. Group 515 alone holds four completely different mechanisms. Group 779 "Rig Launcher" holds a RoF rig, a damage rig and four range/application rigs.
  3. "Is this attribute ID referenced anywhere?" hides gaps. An attribute used for one module can mask the same attribute on another. Examples: attr 548 is read only for Shield Boost Amplifiers but Bastion also carries it; attr 147 is read for Flux Coils, and the MWD's real cap penalty on the same attribute was dismissed as "unrelated"; attrs 309/566 are read only as incoming EWAR.
  4. Skills weren't covered. Energy Pulse Weapons lives on the skill, not the module.

New method used today:

  • Every published module and subsystem (category 7/32), every effect on each item, and the actual pyfa handler for that effect, parsed for which ship/module/drone/charge attribute it changes and with what. That gave 5,317 item×effect×attribute rows.
  • The same pass over every published skill.
  • A stat-centric cross-check: for each number the tool displays, the module groups that change it in pyfa, compared against what the tool's formula actually consumes (read from the code, not inferred).
  • Every finding below was confirmed both ways: the real effect exists in pyfa/SDE, and the tool's formula for that stat doesn't include it.

Checked and not gaps:

  • Turret/drone tracking and application modules. Application is out of scope by design.
  • Overheating attributes. Not modeled anywhere, consistently.
  • Jump/portal/cyno/clone-vat/doomsday "speed −100" effects. These apply only during that activity.
  • Drone speed/durability/range rigs and skills. They don't feed any shown number.
  • Fighter Support Unit. Already logged as deliberately out of scope.
  • Max-locked-targets modules. The tool doesn't display that stat.
  • Capacitor Systems Operation, Repair Systems, Capital Repair Systems duration skills. Already modeled.
  • Reactor Control Unit. Its cap/shield attributes are all 1.0.

Part 4 — Backlog item added: module on/off toggles

Add per-fit toggles for modules that drastically change a fit's stats depending on whether they're running, modeled on the T3 Destroyer mode selector and the capacitor boost toggle.

  • Candidates: Industrial Core, Siege, Bastion, Triage; MWD/AB (boosted vs cruising, already partially split); MJD/MJFG sig bloom; Sensor Booster scripts; cloak.
  • Default stays "active", matching today's behavior.
  • Natural home for implementing the remaining Siege/Triage/Bastion "while active" effects above.
