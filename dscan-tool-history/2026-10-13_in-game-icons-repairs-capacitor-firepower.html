What changed

The new icons come from CCP's image server, the same source as the Fit card's module icons (images.evetech.net/types/{typeId}/icon).

  • Layer colour kept. The repair header icons keep a short underline in the layer's colour (shield cyan, armor amber, hull tan), so they still line up with the coloured layer rows. The armor and hull repairer icons look alike in game, so the colour and the hover text tell them apart.
  • Hover text sits on a plain HTML wrapper, so the native tooltip works.
  • Fallback. If an image can't load (offline, blocked), the old SVG glyph is shown instead.
  • Kept custom: the Break Point icon (no in-game item fits), the shield/armor/hull layer icons (their colours are the layer identity), the info icon and the Tactical Destroyer mode icons. Each mode is an in-game item with its own icon, so the mode icons could be switched later if wanted.
  • Engine: the DPS breakdown rows now carry their type ids (typeId, weaponTypeId), so the card can show the right icon. No numbers changed. The full output diff of every golden fit shows only those new id fields.
