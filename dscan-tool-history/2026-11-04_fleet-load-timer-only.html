Fleet tab: a row's Load counts down as just the time

Page 2026-11-04 · v2026.11.04.6

Why

  • The owner, testing v2026.11.04.5: "load button for individual rows alignment issue. let's drop the "Load in" text while the timer is active. just show the timer until it completes then switch back to "Load"." His screenshot showed "Load in 0:41" wider than the Fit column, so the buttons stuck out past the rows' right edge.

What changed

  • A row's Load shows only the time while zKillboard can't be asked ("0:41"), then "Load". Screen readers hear "Load, in 0:41"; the hover still says why.
  • Load and its countdown are one width (58 px, even-width digits), so the column doesn't shift when one turns into the other. Load all keeps "Load all in m:ss": it has room above the list.

Checks

  • fleet_vs_check.py: the countdown is only the time; Load and the countdown are one width at one right edge, inside the row. The old "Load in 0:41" fails both (100 px against 55 px).
