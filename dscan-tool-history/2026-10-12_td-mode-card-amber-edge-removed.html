TD Mode card -- amber left edge removed

2026-10-12 · dscan-tool.html · same-day follow-up to the TD Mode selector modular-card rework

The request

Immediately after delivering the modular .td-mode-card rework (info link moved into the icon row, click-to-expand preserved, wrapped in a .fit-summary-style container), the owner asked: "in this particular case, we dont need the amber edge on the left."

Why

.fit-summary's border-left:3px solid var(--amber-dim) is the shell every stat card (Firepower, Resistance, Navigation & targeting, Capacitor, Weaknesses, EWAR, Fit) uses -- the amber bar marks "this is a stat card." The TD Mode selector isn't a stat card, it's a control (a mode switcher with an expandable explanation), so the accent no longer fit once it got its own container.

Fix

Added a single scoped override, placed right before the existing .td-mode-row rule:

.td-mode-card{border-left:1px solid var(--line);}

This flattens the TD Mode card's left edge to match its other three sides (all already 1px solid var(--line) via the base .fit-summary rule) -- no change to any other .fit-summary card, which all keep the amber bar.

Playwright: rendered a reference .fit-summary card alongside the TD Mode card and read getComputedStyle on both.
