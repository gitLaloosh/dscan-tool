P2 UI polish — 3 items, autonomous backlog pass

Context: per the owner's instruction ("when you're finished, just continue w/ any backlog items that you can without my input"), after closing the entire P1-A through P1-E comprehensive skill-audit backlog and the Loki sensor-strength re-investigation (both delivered earlier today), these 3 well-scoped P2 UI items were completed without needing further input. All 3 are cosmetic/presentational — no calculation code changed for any of them.

1. EHP/DPS estimate-value visual size parity (CSS only)

The Capacitor card's resistance-total figure rendered visually smaller than the Firepower card's equivalent number, even though both use the same role (a headline stat). Root cause: .resistance-total set font-size:11.5px on the wrapper only — its nested <b> element had no font-size of its own and simply inherited the wrapper's 11.5px, whereas Firepower's equivalent (.estimate-value) sets font-size:20px directly. Fixed by giving .resistance-total b its own explicit font-size:20px; font-weight:600, matching Firepower's figure exactly while leaving the wrapper's label/unit text at 11.5px.

2. Tactical Destroyer Mode selector relocated to top of page

The Mode selector (Sharpshooter/Defense/Propulsion icon row + its "how this is handled" disclosure) was previously inline inside the Weaknesses card's template, buried partway down the Fit Analyzer output. Extracted it out of renderFitSummaryHtml()'s inline markup into its own standalone function, tacticalDestroyerModeSelectorHtml(f), and moved its call to the very top of the returned card stack — now the first thing rendered for any fit that has tactical modes at all, ahead of EWAR/Firepower/Resistance/Weaknesses/Nav/Capacitor. Also adjusted its CSS (.td-mode-row margin) since it's no longer nested inside a card's own padding.

3. Turret ammo recommendation: 1 lumped tile -> 3 per-weapon-system tiles

The Weaknesses card's ammo-recommendation row previously gave the Missile tile a precise single-ammo answer (e.g. "Mjolnir (pure EM)") but lumped all 3 turret weapon systems into one vague sentence (e.g. "Laser crystals — Multifrequency/Radio lean EM-heavy"). Replaced the single "Turret" tile with 3 separate tiles — Laser, Hybrid, Projectile — each naming the single best charge for the target's weakest damage type, at the same precision as the Missile tile, or explicitly stating when that weapon system cannot address the type at all (rather than guessing a strained answer).

Built from live ESI dogma on every named T1 charge tier at all 4 sizes (item groups 85 "Hybrid Charge", 86 "Frequency Crystal", 83 "Projectile Ammo"; damage attributes 114=em, 116=exp, 117=kin, 118=therm), per this project's standing grounded-verification rule:

  • Frequency Crystal (laser) carries only EM+Thermal damage, and on every one of the 8 named tiers (Radio/Microwave/Infrared/Standard/Ultraviolet/Xray/Gamma/Multifrequency) Thermal never exceeds EM — not even on Multifrequency, the most Thermal-leaning tier. Lasers can therefore never be the purest answer for a Thermal weakness, and can never address Kinetic or Explosive at all. Radio is the single purest EM crystal (100% EM, 0 Thermal) — the EM-weakness recommendation.
  • Hybrid Charge carries only Kinetic+Thermal damage, and Kinetic is majority on every one of the 8 named tiers (Iron through Antimatter), ratio roughly 1.33:1 to 1.5:1 — none is dramatically "purer" than another. Hybrids can never be purely Thermal, and can never address EM or Explosive at all. Antimatter is the standard high-damage Kinetic choice (Kinetic weakness); Iridium/Thorium lean slightly more Thermal-ward than the rest, the closest a hybrid gets to a Thermal answer (used for the Thermal-weakness recommendation, with a note that it's still Kinetic-majority).
  • Projectile Ammo is the only turret family spanning all 4 damage types: EMP (EM-heavy) for EM weakness, Fusion (pure Explosive) for Explosive weakness, Titanium Sabot (best available Kinetic lean via this weapon system) for Kinetic weakness, Phased Plasma (genuinely Thermal-dominant) for Thermal weakness.

Implemented as a new TURRET_RECS table (damage type -> {laser, hybrid, projectile}, each either {name, note} or null when that weapon system can't meaningfully address the type), with a new turretRecTileHtml() helper for the Fit Analyzer's boxed rec-grid tiles and a parallel turretRecText() helper reused by the simpler plain-text .rec block in the main D-Scan summary card (which had the exact same lumped-turret-string problem and needed the identical fix to avoid breaking when the old RECS[...].turret field was removed). .rec-grid/.rec-stat CSS updated to wrap (flex-wrap:wrap, min-width:140px) since the row now holds 5 tiles (Drone/Missile/Laser/Hybrid/Projectile) instead of 3.
