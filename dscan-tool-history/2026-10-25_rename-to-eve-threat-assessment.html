What stays, on purpose

  • The D-Scan Analyzer tab keeps its name: it is the part that reads directional scans.
  • The browser storage keys (dscanMyShip, dscanDmgPreset, dscanFitView) and the item cache database (dscan-tool-cache). Renaming them would wipe everyone's saved ship and cache.
  • The repo name dscan-tool, and so the GitHub Pages address, plus the file and folder names (dscan-tool-history/). Renaming the repo is the owner's call on GitHub. GitHub redirects the repo, but the Pages address changes and old links to the page break.

Before deciding, a web search found two EVE forum tools with similar names, "EVE Threat Checker" and "Eve Threat for Blops". the owner kept "EVE Threat Assessment".

Lesson for future models

LESSON #56: a rename changes what people see, not where their data lives. Rename the visible text, keep storage keys, database and repo names, say so in a comment, and check that data saved before the rename is still read. Also: to check two things don't overlap, measure what is drawn. The h1's full-width box always "overlapped" the version tag; the text's own rects are what can collide.
