Weapon Range/Falloff fix — 2 missing turret range skills (comprehensive skill audit, P1-C)

Context: third item in the phased sub-backlog from the comprehensive skill audit (P1-A Fighters and P1-B Drones were delivered earlier today). This closes out the turret half of Finding C — the Weapon Range/Falloff feature (shipped 2026-10-10) assumed max-level damage/RoF skills everywhere else in this tool but never checked whether any skill touched optimal range or falloff at all.

What was wrong

Two real skills were entirely unmodeled in the turret optimal-range/falloff calculation:

  • Sharpshooter (3311): own ESI description "5% bonus to weapon optimal range per skill level" → +25%@V.
  • Trajectory Analysis (3317): "5% bonus per skill level to weapon turret accuracy falloff" → +25%@V.

Both skills' own dogma effects are gated on the weapon requiring Gunnery (type 3300) — but confirmed live this is not always the same reqSkill slot: a plain energy/hybrid/projectile turret (checked Neutron Blaster Cannon II, 650mm Artillery Cannon II, Mega Pulse Laser II) carries Gunnery as reqSkill2 (attribute 183), while the Triglavian Entropic Disintegrator carries it as reqSkill1 (attribute 182) instead. So the check has to test all 3 reqSkill slots generically (reusing the existing REQUIRED_SKILL_ATTRS=[182,183,184] array already in the file for sentry/drone-skill classification), not assume a fixed slot.

Also confirmed live that EDENCOM's Vorton Projector does not require Gunnery at all — it carries its own unrelated skill-tree ids (55033/55035/54828) in those same 3 slots, consistent with the comment already on file describing Vorton's separate 3-skill tree (Vorton Projector Operation/[size] Vorton Projector/[size] Vorton Specialization). So Sharpshooter/Trajectory Analysis correctly do not apply to Vorton weapons — confirmed by checking the real Stormbringer golden fit's Medium Vorton Projector II, unaffected by this change.

What changed in dscan-tool.html

  • New constants: GUNNERY_SKILL_ID = 3300, MAX_SHARPSHOOTER_RANGE_MULT = 1.25, MAX_TRAJECTORY_ANALYSIS_FALLOFF_MULT = 1.25.
  • In the confirmed-loaded-charge turret range branch: gunneryGated = REQUIRED_SKILL_ATTRS.some(attrId => attrVal(weaponDogma, attrId, 0) === GUNNERY_SKILL_ID); when true, optimalM and falloffM are each additionally multiplied by their respective skill constant before rounding.
  • Updated the in-app methodology disclosure note to mention Sharpshooter/Trajectory Analysis are assumed max-level, except on Vorton weapons which don't train on them.

Magnitude

Example (Neutron Blaster Cannon II + Void L, the real popejoy's Megathron golden fit): base 7200m optimal/10000m falloff × Void L's own 0.75/0.5 ammo multiplier = 5400m/5000m before this fix → 6750m/6250m after (×1.25/×1.25). A ~25% increase in both displayed numbers for every Gunnery-trained turret fit. Vorton Projector fits are completely unaffected (19200m/0m, unchanged).

Verification

  • The Weapon Range/Falloff feature had zero regression coverage at all before this fix (confirmed — no golden fit asserted on optimalM/falloffM/travelDistanceM, and run_regression.mjs had no flattening for rangeEstimates). Added both: a new flattening block (rangeOptimalM/rangeFalloffM/rangeTravelDistanceM, first-match idiom) and expected-value assertions on the 2 real fits that happen to already carry a confirmed-loaded turret.
  • megathron_popejoy (Neutron Blaster Cannon II/Void L, Gunnery-gated): hand-derived 7200×0.75×1.25=6750m optimal, 10000×0.5×1.25=6250m falloff — sandbox produced 6750/6250, exact match.
  • stormbringer_zkb138986635_vorton (Medium Vorton Projector II, confirmed not Gunnery-gated): hand-derived 38400×0.5=19200m optimal (no falloff attribute exists on this weapon at all) — sandbox produced 19200/0, exact match, confirming the skill correctly does NOT apply.
  • Not pyfa-cross-checked — pyfa doesn't expose a skill-by-skill breakdown of its own range calculation to diff against; grounded in each skill's own live ESI description text plus the reqSkill-slot verification above instead, same bar as every other skill-audit fix this session.
