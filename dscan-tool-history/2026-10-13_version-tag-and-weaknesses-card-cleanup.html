Version tag + Weaknesses card background/alignment cleanup

2026-10-13 · index.html · Erik: "let's start including an actual version number on the page so we're always clear about which version of the tool we're talking about when troubleshooting or testing something. and get rid of that yellow background in the weaknesses card, doing so should also fix the alignment difference between weaknesses and the other cards."

1. Version tag

New small v2026.10.13.1 label in the top-right corner of the page header (inside header.hero, which was already position:relative -- the tag is absolutely positioned off that, no layout changes elsewhere). Format is YYYY.MM.DD.N: N is a same-day sequence number, starting at 1 on a new calendar date -- this project has repeatedly shipped 3-5 separate same-day changes in one sitting (today included), so a bare date alone wouldn't disambiguate between those. Hardcoded directly into the static HTML (not JS-rendered), so it's visible immediately in view-source or DevTools with zero dependency on script execution succeeding. Carries hover text explaining its purpose. Convention going forward: bump this literal string by hand on every future delivery that changes index.html -- same day, increment N; new day, reset to .1. No version existed before this; the count starts fresh from here (not retroactively applied to earlier same-day fixes, which had no on-page tag to increment from).

2. Weaknesses card background/alignment

Long-filed backlog item, closed. .weakness-highlight (the div wrapping the weakest-damage-type badge, capacitor gauge, and drone/turret rec grid inside the Weaknesses card) previously carried its own background:rgba(217,154,60,0.06) amber tint, a var(--amber-dim) border, and padding:12px 14px -- on top of the outer .fit-summary card's own 16px 18px padding. No other card (EWAR/Misc, Firepower, Resistance, Navigation&targeting, Capacitor) nests anything with its own extra padding inside .fit-summary, so Weaknesses' content sat visibly inset relative to every card stacked below it. Dropped the background/border/padding entirely; kept the display:flex; flex-direction:column; gap:12px; margin-bottom:12px; rules, since those are internal layout (spacing between the badge row/gauge/rec-grid), not the box look.
