Collapsible "how this is calculated" info panels

Date: 2026-10-10   Status: Delivered, verified in real Chromium, 28/28 regression PASS, byte-identical diff

Requested by Erik: the long explanatory paragraphs under a Pilot Analyzer fit result — how effective HP and DPS are calculated, and how Tactical Destroyer Mode is handled — should be tucked into a collapsible panel that defaults to collapsed, with a small "i" info icon, instead of always taking up space.

The change

Both explanatory blocks are now wrapped in a native <details class="info-disclosure"> element with a <summary> row (a small circled-"i" icon + a one-line label: "How effective HP and DPS are calculated" / "How Tactical Destroyer Mode is handled"). Collapsed is the default — no open attribute in the markup — and clicking the summary row expands it in place. Using the browser's native <details> means no JavaScript/state wiring was needed at all, and it degrades gracefully (stays readable, just not collapsible) in the unlikely case a browser ignores it.

The actual numbers (effective HP, total DPS, the HP breakdown, the Mode icon buttons) are untouched and still always visible — only the long prose explaining the methodology is now tucked away.
