Firepower audit findings (hand-tables plan, Phase 1)

Findings onlyTooling 2026-10-14 · index.html unchanged (v2026.10.14.1) · Erik: "ok go ahead"

What was done

  • New tools/audit_firepower.py. It runs every pyfa handler that changes weapon, drone or fighter damage or rate of fire, on all 393 hulls that carry one (published or not), plus subsystems, modules, rigs and skills. It diffs the result against the tool's hand-built tables and records each bonus's real scope (weapon size, missile family, damage type). It also reports drone control range.
  • Recorder change: tools/pyfa_effects.py now records fit.extraAttributes (drone control range). dump_effect_tables.mjs takes an optional list of table names.
  • Reference: pyfa v2.69.2 with game data 3579973, the same as Erik's pyfa. Full report: Claude outputs/firepower_audit_2026-10-14.txt.

Headline

Of the tool's 352 hand-typed hull entries, 333 match pyfa exactly on value, kind and damage type. The skill constants (Gunnery, Rapid Firing, Surgical Strike, size skills, missile skills, drone and fighter skills) match too, with the exceptions below. The real problems:

Damage-type and weapon-type coverage

  • Nemesis (thermal torpedoes only), Virtuoso (thermal + explosive) and Caiman (kinetic + thermal): these bonuses are damage-type-restricted in pyfa, but the tool applies them to every type. Off-type ammo is overstated by 75% / 75% / 25%. The other three stealth bombers were already restricted correctly.
  • Gnosis, Sunesis, Praxis, Metamorphosis: the role bonus covers all turrets. The tool only covers hybrids and missiles, so lasers and projectiles miss +20% (Metamorphosis +80%).
  • Caiman, Komodo: +100% to fighters' turret-attack ability (role bonus) is missing.

Skills and modules

  • Vorton Power Amplification (+3%/level damage to every Vorton Projector) is missing. The tool's comment describes a three-skill Vorton tree; current data has a fourth skill. All Vorton DPS is 13% low (÷1.15). This is the only finding that touches an existing golden fit (stormbringer_zkb138986635_vorton).
  • Fighters get no fitted-module damage bonus. In pyfa, Drone Damage Amplifiers (and the hybrid modules below) also boost fighters, but the tool never fills its fighter module pool. Carrier and supercarrier fighter DPS is low by the whole DDA stack.
  • Faction and Abyssal damage modules with a drone bonus: Imperial Navy 'Neophyte'/'Disciple' Heat Sinks, Federation Navy 'Argyreos'/'Khryseos' Magnetic Field Stabilizers, C3 'Hivaa Saitsuo' BCSs and the Abyssal versions all carry the Drone Damage Amplifier effect. The tool reads drone bonuses only from the "Drone Damage Modules" group, so these are ignored.
  • Known items, now confirmed:
    • XL Torpedo and XL Cruise Missile Specialization missing (2%/level RoF on T2 XL launchers)
    • Skua Sharpshooter Mode missing from the mode table (+33.3% missile damage)
    • Mutated Drone Specialization not in the racial drone list (niche)

Scope (lower priority)

314 hulls have bonuses that pyfa limits to one weapon size or missile family. Examples: Megathron, Large Hybrid only; Caracal, heavy/HAM/rapid-light launchers only. The tool applies them to the whole weapon type. The 282 size-limited turret bonuses and 147 missile-family limits only matter for off-size or off-family fits, such as a Caracal with light missiles. The generated table will carry the scope, as the weapon-range table already does.

Matches worth noting

  • Drone control range: pyfa has exactly two hull sources, Ishtar +25 km and Griffin Navy Issue ×0.5, and both match the tool.
  • The Tactical Destroyer Sharpshooter modes (+33.3% damage) match for the four hulls in the table.
  • The Griffin Navy Issue −70% drone malus matches. pyfa applies it per damage type.

Not comparable

Seven special-edition hulls (Moros Interbus, Naglfar Justice, Phoenix Wiyrkomi, Revelation Sarum, the two Punisher editions, Rorqual ORE Development) carry no damage effects in the SDE, so pyfa gives them no bonus. The tool gives them the base hull's bonus (known open item #4). This stays a deliberate, disclosed deviation.

Recommended fix (next step)

  1. Generate the hull/subsystem damage table from pyfa, like the weapon-range table: effect → rows of [weapon category, damage or RoF, source attribute, per level, skills, groups, damage type]. Apply it per weapon instance, so scope and damage type are exact. Keep SHIP_ROLE_BONUS only as the fallback for hulls with no effects (the special editions). This fixes every hull finding above in one change.
  2. Modules: read the drone bonus from the attribute on any module, not the group, and add DDA/hybrid-module bonuses to fighters.
  3. Skills: add Vorton Power Amplification ×1.15 and the XL missile specializations. Modes: add the Skua.
  4. Tests: derive expected values first (independent check script), then add constructed golden fits that fail on today's build:
    • Leviathan
    • Anhinga
    • Akoman
    • Thunderchild
    • Nemesis with off-type ammo
    • Gnosis with lasers
    • Thanatos with DDAs

Lesson for future models

The first audit runs reported ~160 mismatching hulls. Most were the audit's own mistakes:

  • a missing attribute read as 0 instead of its default, which invented a −100% light-fighter penalty on every carrier
  • one bonus split across four effects, or across launcher families
  • charge filters that test the launcher
  • drone damage-type boosts
  • unpublished special-edition hulls

Open a few mismatches by hand before trusting the list. See LESSONS_LEARNED.md #22.
