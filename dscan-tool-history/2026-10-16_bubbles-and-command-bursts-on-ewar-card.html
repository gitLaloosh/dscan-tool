  • Buff wording follows pyfa's __runCommandBoosts: shield / armor damage taken, repair cycle and cap, HP, scan resolution, EWAR range and strength, sensor strength, signature, web and scram range, AB / MWD speed, targeting range, agility, and the mining / expedition buffs.
  • Only bursts that are online count. pyfa's group limits still apply: one burst per hull, two on a Command Ship.
  • A booster's bursts don't change its own stats; pyfa only applies them to fleet members.

How (PYFA CORE ewar-calc, re-verified and re-locked)

  • gen_ewar_table.py: WDFG and Command Burst groups added; new attributes warpScrambleRange, warfareBuff1-4Value, buffDuration.
  • New row target 'charge' (pyfa filteredChargeBoost), with the charge attributes listed in EWAR_CHARGE_ATTRS. pyfaEwarSetup computes the loaded charge's modified attributes first. A 'self' row reading one of them uses that modified value, as pyfa's getModifiedChargeAttr does.
  • An early-runtime row is kept when it is order-independent: a boost or multiply whose source attribute no pyfa handler ever writes (checked against effects.py). Examples: Industrial Core burst rows, Laelaps WDFG sig.
  • Charges loaded in high slots now pair with their module, as mid-slot scripts already did.

Two real gaps found on the way (both now pyfa-exact)

  • An active bubble blooms the Heavy Interdictor's own signature (pyfa Effect3380: +signatureRadiusBonus, unpenalized, only without a script). The Onyx showed 150 m where pyfa has 225 m. Now modelled from the module's modified signatureRadiusBonus, the same ewar-calc value; Laelaps cuts it via Effect8362.
  • Warp Disruption Scripts change cap need and cycle (Effect804 capNeedBonus, Effect3602 durationBonus). The Focused script showed 112.5 GJ / 30 s where pyfa has 45 GJ / 6 s. Each scripted copy now gets its own drain entry. An ASB's charge is excluded, since its capNeedBonus is the ASB's own "runs on charges" rule.

  • compare_ewar.py now also compares bubble radius, probe lifetime, burst range, duration and every buff: 0 mismatches (96 entries). compare_fit_stats.py: 0 mismatches (223 fits); it flagged the two gaps above. gen_ewar_table.py: up to date.

  • Full output diff v.25 → v.26: the 4 new fits, plus 7 existing fits whose bursts are now listed (Nighthawk, Prophecy, Damnation, and the Rorquals' Mining Foreman Burst). No other number moves.

Lesson for future models

  • Test fits built for one feature check every stat. The all-fit pyfa comparison found two gaps in signature and capacitor that had nothing to do with the card being built. Run compare_fit_stats.py on every new fit, not only the check for the feature.
  • When pyfa reads a charge's attribute (getModifiedChargeAttr), the value includes the charge's own modifiers. Model the charge's attributes first, then the module's.
