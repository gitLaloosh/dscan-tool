Weapon range: modules, scripts, rigs, Bastion and hull bonuses

Feature backlogAudit batch 7 2026-10-13 · v2026.10.13.16 → v2026.10.13.17 · Erik: "keep going"

What was missing

Turret optimal/falloff and missile travel distance used the weapon, the loaded ammo and the range skills. A hand-made table added hull range bonuses for five hulls only. No module, rig or script changed range, and missiles got no hull bonus at all.

How the new table was built

Earlier batches parsed pyfa's handlers with text matching. That misses handlers that loop over attribute names or pick values by context (dozens of the range handlers, including the Raven's and the Tracking Computer's). This time each real pyfa handler was executed against a recording stand-in for the fit. That captured exactly which attribute it changes, by what source attribute, with which skill scaling and stacking group. Each handler's filter was then evaluated against every published turret (642) and missile charge (200) in CCP's SDE.

Result: WEAPON_RANGE_MOD_EFFECTS, 153 effects carried by ships, modules, rigs and subsystems:

Not included

  • Remote Tracking Computers, gang boosts and Tracking/Guidance Disruptors are projected effects, out of scope.
  • Drone and fighter range, implants and boosters (Deadeye, Blue Pill, Crash) are separate items.
  • Overheating isn't modeled anywhere.

Lesson for future models

The earlier batches found pyfa's bonus code by text matching eos/effects.py, and that misses handlers that loop over attribute names or pick values by context. Run the real handlers with tools/pyfa_effects.py instead, and regenerate this table with tools/gen_weapon_range_table.py. See LESSONS_LEARNED.md #1 and #4.
