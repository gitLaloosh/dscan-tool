EWAR effectiveness bonuses — hull/subsystem/skill layer (2026-10-11)

Closes the "KNOWN GAP" explicitly flagged when the base EWAR capabilities card shipped on 2026-10-11 (same day): v1 of that card read each fitted ECM/Sensor Dampener/Target Painter/Tracking+Guidance Disruptor/Stasis Web/Warp Scrambler module's own stats only, with no account for Recon Ship hull bonuses, T3 subsystem bonuses, or the universal skills (Long Distance Jamming, Signal Dispersion, Signature Focusing) that boost these modules regardless of hull. This delivery adds that whole layer, after the owner's explicit pyfa-validation gate: six constructed/real fits (Curse, Huginn, Lachesis, Rook, Tengu, Proteus) were each predicted, then checked one at a time against real pyfa output before anything was delivered. Two real bugs were found and fixed during that validation — see below.

What changed in dscan-tool.html

  • New falloffM field on every ewarModules entry — the module's own falloff range (attribute 2044, meters), present on ECM/Sensor Dampener/Target Painter/Tracking+Guidance Disruptor (confirmed absent on Stasis Web/Warp Scrambler), boosted +50%@V by the universal Frequency Modulation skill. The EWAR card now shows it the same way pyfa does: range+falloff km (e.g. "54+135 km").
  • EWAR_UNIVERSAL_SKILL_BONUS — applies regardless of hull, all at assumed max skill level V: Long Distance Jamming +50% optimal range (ecm/damp/paint/trackingDisruptor/guidanceDisruptor); Frequency Modulation +50% falloff range (same 5 kinds); Signal Dispersion +25% ECM jam strength; Signature Focusing +25% Target Painter signature bonus; Signal Suppression +25% Sensor Dampener targeting-range/scan-res suppression; Weapon Destabilization +25% to all 7 Tracking/Guidance Disruptor magnitude attributes.
  • SHIP_EWAR_BONUS — per-hull Recon Ship bonuses, keyed by ship type id: Rook/Falcon +150% ECM jam strength; Huginn/Rapier +300% web range, +50% paint signature bonus; Lachesis/Arazu +100% scram range, +37.5% damp suppression; Curse/Pilgrim +37.5% to all 7 Tracking/Guidance Disruptor magnitude attributes.
  • SUBSYSTEM_EWAR_BONUS — T3 Core subsystem bonuses: Tengu Core - Obfuscation Manifold +50%@V ECM jam strength/range; Proteus Core - Friction Extension Processor +37.5%@V Warp Scrambler/Disruptor range.
  • RIG_EWAR_BONUS — Signal Distortion Amplifier I/II: +7%/+10% flat ECM jam strength and range.
  • 2 new Guidance Disruptor fields (explosionVelocityBonusPct/explosionRadiusBonusPct) added so the Curse/Pilgrim hull bonus visibly covers all 7 of its real targeted attributes, not 5.
  • Fixed a latent regression-harness bug (closeEnough() in run_regression.mjs computed tolerance as unsigned expected * tol, always false for negative expected values) — found while adding the first negative-percentage assertions.
